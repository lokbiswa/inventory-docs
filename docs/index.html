What this app does

Inventory Promos applies the mix-and-match promotions you create in the inventory system (for example, “any 2 Red Bull for $5”) on Clover Register.

  • It reads Clover inventory (items and tags) to see which items are eligible for a promotion.
  • It reads and updates open orders only, adding or removing line-item discounts named Promo: {name}.
  • Promotion rules are stored on the register and on the merchant’s inventory server.

The app does not collect customer card data and does not sell data.
